# AI Transparency

As stated in my profile description, I want to be transparent about how I use
AI in my projects.

I used Codex for this project.

**THE SOURCE CODE, EXAMPLES, AND DOCUMENTATION WERE CREATED WITH THE HELP OF
AI.**

### Research

AI helped with research about the Arduino library structure, Arduino IDE
compatibility, and the requirements for publishing an Arduino library.

### Coding

Codex helped create and refine the PLCBlocks source code.

### Documentation and Examples

Codex helped create the README and the example sketches included with the
library.

### Testing

The code and examples were compiled and checked with automated tests.

## My Stance on AI

While I use AI as a programming tool, I strongly oppose using AI to copy,
imitate, or take credit for other people's projects, artwork, or creative work.

I am personally against the generation of AI-created images and artwork,
especially when it replaces, imitates, or undermines the work of human artists.

Whenever possible, I prefer to support human artists and creators and respect
the time, skill, and creativity behind their work.

AI should be a tool - not an excuse to take someone else's work.
